# Observations

Signals for improving the instruction files, skills, and hooks.

Two kinds of entry go here:

- **Hook and skill fire logs** — written automatically. See `hook-log.md`.
- **Session findings** — recurring problems, instruction gaps, and things worth repeating. Written by
  hand at the end of a session, and only when the finding is worth acting on.

The point is evidence. A rule that never fires, or fires constantly, is a rule that needs changing.
